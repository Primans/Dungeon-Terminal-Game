# Dungeon Game

A simple text-based RPG developed in C# as a console application.

In this game, you explore a dungeon, fight enemies, earn rewards, level up your character and buy upgrades to become stronger.

## Features

- **Combat System** – Fight different enemies using your character's damage and defence.
- **Leveling System** – Gain experience from defeating enemies and level up to improve your stats.
- **Inventory System** – Collect and store items such as health potions.
- **Shop System** – Spend gold on health potions, weapon upgrades and armour upgrades.
- **Save & Load** – Save your character's progress and load it again later.
- **Character Stats** – Keep track of your health, damage, level, experience, gold and defence.

## Built With

- C#
- .NET 9
- Visual Studio Code

## Save System

The game uses a simple text file (`save.txt`) to store your progress.

The save file is created in the project folder and contains your character's stats and inventory.

## About the Project

This project was created to practice programming in C# and learn more about object-oriented programming, methods, classes, lists and file handling.
